Быстродействие

Первым делом

  1. Сжатие CSS, HTML, JS
  2. Спрайты - Smart Sprites, Spritesmith, SVG (grunt-svgstore)

Графика

  • Imagemin, только по измененным файлам с grunt-newer
  • SVGO
  • WebP + grunt-webpcss + grunt-webp

CSS

  • Умные компрессоры, как CSSO
  • Объединение Media Query (grunt-combine-media-queries)
  • Чистка лишнего CSS и JS (grunt-uncss, Google Closure)
  • Генерация Critical CSS c запущенного сайта (penthouse)

Как мерить

Помимо статистики пользователей:
  • Google PageSpeed + Grunt
  • Тесты c PhatnomJS или Selenium + Sauce Labs
  • Скриншоты загрузки на медленных соединениях (grunt-load-perf)
  • Сравнение веса ресурсов (grunt-compare-size)

Проверка кода

Анализируем все

  • JS Lint, Hint и сразу таблетка (grunt-fixmyjs)
  • CSS Lint
  • HTML inspector
  • Coffee, Less, SCSS, JSON, jQuery
