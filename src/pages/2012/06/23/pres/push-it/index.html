Кнопка, ссылка, псевдоссылка? Как правильно выбрать, сверстать и не наделать глупостей.

Ссылки

Псевдоссылки

Ссылка

Ссылка

				<a href="http://…">Ссылка</a>
  • Основа гипертекста, лучший друг поисковика
  • Переход между документами самым явным образом
  • Привычна и удобна, как ничто другое

Главное — адрес

Логическая ссылка

				<ul>
				    <li><a href="/">Главная</a></li>
				    <li><a>Каталог</a></li>
				    <li><a href="/about/">О компании</a></li>
				</ul>

Чисто логическая ссылка, без адреса

Не ссылка

Если у ссылки нет адреса, внутреннего, внешнего или логического, то это не ссылка, т.е. не <a href=""> и даже не <a>

Ведь пользователь может…

Пользователь может

  • Кликнуть с модификатором и открыть в фоновой вкладке
  • Перетянуть на панель закладок или на рабочий стол
  • Кликнуть правой кнопкой и скопировать адрес
  • Взаимодействовать с помощью расширений и программ

Когда ссылка — ссылка

Псевдоссылка

Псевдоссылка

				<a href="#anchor">Псевдоссылка</a>
  • Некоторое действие на той же странице
  • Якоря, подстановка текста в формы, открытие выпадушки
  • Стала де-факто стандартом для этого круга действий

Но это не обязательно ссылка…

Псевдонессылка

				<span class="pseudo-link">Псевдонессылка</span>
  • Если у псевдоссылки нет адреса, внутреннего или внешнего
  • Становится очень похожей на кнопку, но тише и проще

Существует договорённость…

Тоненьким пунктиром

				.pseudo-link {
				    border-bottom:1px dotted;
				    }
  • Стиль dotted выглядит чище, чем dashed
  • Цвет можно не указывать, он наследуется от текста
  • Можно рисовать пунктир картинкой и даже градиентом

Кнопка

				<input type="submit" value="Кнопка">
				<input type="button" value="Кнопка">
				<input type="image" src="…">
  • Действия, связанные с отправкой данных, некоторым процессом
  • Самый привычный системный элемент: ДА или НЕТ?!
  • Делать лапу cursor:pointer совсем не нужно

The button element represents a button.
The element is a button.

Кнопка «Кнопка»

				<button type="button">Кнопка</button>
				<button type="submit">Кнопка</button>
				<button type="reset">Кнопка</button>

Универсальный элемент для использования вне форм

JavaScript

Сделай-ка мне, чтобы по ссылке так дыщ! и выплывало…

Безумные ссылки

				<a href="#" onclick="fire()">
				    Бах!
				</a>

Берём, значит, ссылку и вешаем обработчик

Безумные ссылки

				<a href="javascript:fire()">
				    Бдум!
				</a>

Можно задействовать пустой атрибут

Безумные ссылки

				<a href="javascript:void(0)" onclick="fire()">
				    Ды-дыщ!
				</a>

Или даже всё сразу!

Но ссылки-то нет!
