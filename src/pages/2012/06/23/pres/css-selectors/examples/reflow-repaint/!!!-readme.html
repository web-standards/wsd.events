Загрузка страниц в замедленном режиме

К сожалению, для демонстрации данного примера недостаточно одного лишь браузера — необходим также веб-сервер и PHP версии 5. Файлы, располагающиеся в этом каталоге, необходимо разместить в корневом каталоге дерева документов сервера. Если адрес хоста — 127.0.0.1, так будут выглядеть ссылки на демки, упоминаемые в презентации доклада:

  • http://127.0.0.1/demo.php
  • http://127.0.0.1/demo-menus.php
