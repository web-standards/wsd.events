Этапы разработки

  1. Смысл документа, логическая разметка (HTML)
  2. Внешний вид (CSS)
  3. Безупречный внешний вид (CSS3)
  4. Взаимодействие, интерактивность, удобство (JavaScript)

Сначала мобильные (Mobile First)

Рекомендации от Люка Вроблевски

  • использование спрайтов
  • минимизация CSS и JavaScript файлов
  • ограничение использования тяжелых JavaScript библиотек
  • ограничение использования CSS-сеток
  • HTTP-заголовки для сохранения нужных файлов в кэш
  • использование CSS3 для теней и закругленных углов
