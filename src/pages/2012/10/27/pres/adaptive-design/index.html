Основные принципы адаптивного веб-дизайна

  1. Fluid Grids — подвижные («резиновые») сетки
  2. Flexible Images — гибкие изображения
  3. Media Queries — медиавыражения

Fluid Grids

Пример макета

#main
760px
#sidebar
220px
980px
					#main {
					  float:left;
					  width:760px;
					  }
				
					#wrapper {
					  width:980px;
					  margin:0 auto;
					  }
				
					#sidebar {
					  float:right;
					  width:220px;
					  }

Формула Итана Маркотта

				target / context = result
			
				#main {
				  float:left;
				  width:  77.551%;    /* 760px / 980px = 0.77551 */
				  }

				#sidebar {
				  float:right;
				  width:  22.449%;    /* 220px / 980px = 0.22449 */
				  }
			
				#wrapper {
				  width: 100%;
				  max-width:980px;
				  margin:0 auto;
				  }

Media Queries

Пример макета

Бытует масса легенд о том, что среди синеоких тайских кошек-красавиц больше всего ценились при дворцах те, что имели многочисленные крючки и изломы на хвостах. Якобы на них тайские принцессы нанизывали свои кольца, снятые на время купания. Современные кошки Таиланда, как и тайские кошки России, изобилуют укороченными, искривленными или закрученными хвостами. Исторически являясь носителями генов дефектов хвостов, тайские кошки стали прародителями новой российской породы куцехвостых кошек — тайского бобтейла.

				@media screen and (max-width:320px) {
				  #main, #sidebar {
				    float:none;
				    width:100%;
				    }
				  }

Mobile First

Отсекаем все лишнее

Полезные правила Mobile First

  • использование спрайтов
  • минимизация CSS и JavaScript файлов
  • ограничение использования тяжелых JavaScript библиотек
  • ограничение использования CSS-сеток
  • HTTP-заголовки для сохранения нужных файлов в кэш
  • использование CSS3 для теней и закругленных углов
