Что классного в jQuery?

  • Классный chaining API
  • Отличные возможности для расширения ✓
  • Не менее отличные функции общего назначения ✓
  • Самая популярная библиотека на сегодня

Зачем расширять jQuery?

  • Выше шанс для повторного использования кода
  • Тесная интеграция с базовым функциями jQuery
  • Большая база готовых решений
  • Лучшая организация кода

jQuery.fn. Выводы

  • Можно реализовать видимость методов
  • Мы изобрели jQuery UI Widget Factory
  • В jQuery UI 1.9 можно делать виджеты без привязки к нодам
  • Удобнее представлять отдельные сущности - виджеты, неудобно представлять все остальное - сетевое взаимодействие и пр.

jQuery.fn. Признаки хорошего плагина

  • Работает с коллекциями из нескольких элементов
  • Отдельные параметры для каждого элемента коллекции
  • Позволяет с собой общаться
  • Использует правильное API jQuery для нужных целей.
  • Лежит в свободном доступе на github.com или подобном портале

Opensource - это хорошо!

src/event.js

$.fn.on. Зачем это?

  • Событие должно быть событием
  • Callbacks sucks
  • Широкие возможности для отладки
  • Реализация новых событий DOM-элементов (devicerotate)
  • Любые сообщения от вашего виджета
  • Шина для получений информации извне (например, longpolling)
