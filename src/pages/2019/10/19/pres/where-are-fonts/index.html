Web font tools

            brew install woff2 sfnt2woff-zopfli
            woff2_compress din.ttf               >> din.woff2
            sfnt2woff-zopfli din.ttf             >> din.woff

чтобы разжимать файлы обратно, если нужно.

Загрузка

Как работают шрифты

  1. Загружаем и парсим HTML, находим стили
  2. Загружаем стили, находим шрифты
  3. Сравниваем стили и текст, решаем какие шрифты нужны
  4. Загружаем шрифты
  5. Рисуем интерфейс

Стилизация

Прямое начертание 

            @font-face {
                font-family: 'Rubik';
                font-style: normal;
                font-weight: normal;
                src: url('rubik-regular.woff2') format('woff2'),
                     url('rubik-regular.woff') format('woff');
            }

Курсивное начертание 

            @font-face {
                font-family: 'Rubik';
                font-style: italic;
                font-weight: normal;
                src: url('rubik-italic.woff2') format('woff2'),
                     url('rubik-italic.woff') format('woff');
            }

Полужирное начертание 

            @font-face {
                font-family: 'Rubik';
                font-style: normal;
                font-weight: bold;

            }
